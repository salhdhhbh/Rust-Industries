# Rust Industries 0.1.5 — Native Crusher

این پوشه سورس Native نسخه 0.1.5 برای Starling 0.9.0 و Horizon Mod API 0.2 است.

- شناسه: rust_industries
- نسخه: 0.1.5
- بلوک ماشین: rust_industries:crushing_wheel
- ورودی/خروجی Crusher: دو خانه
- زمان پردازش: 40 تیک
- خروجی: دو پودر آهن، مس یا طلا متناسب با ورودی
- ظرفیت انرژی: 20,000 FE
- مصرف انرژی: 50 FE در هر تیک فعال (2,000 FE برای هر چرخه کامل)
- ورودی انرژی: از هر شش سمت
- خروجی انرژی: غیرفعال؛ انرژی از خود Crusher قابل برداشت نیست
- در صورت کمبود انرژی، پیشرفت حفظ می‌شود و پردازش پس از شارژ ادامه می‌یابد
- در صورت پر بودن خروجی، انرژی مصرف نمی‌شود و پیشرفت حفظ می‌شود

## ساخت

این پوشه را به‌عنوان پروژه مستقل باز کن و از لانچر Horizon/Starling برای Native Build استفاده کن. فایل Cargo.toml به SDK پین‌شده در .horizon/sdk وابسته است؛ ابزار Horizon در نخستین Build آن را دریافت می‌کند. برای اجرای کد Native باید سورس را بررسی و به اجرای آن اعتماد کنی.

این سورس در محیط آماده‌سازی کامپایل نشده است؛ بنابراین commitها به معنی تأیید موفقیت کامپایل یا اجرای داخل بازی نیستند. فایل توزیعی .hmod شامل دارایی‌ها و داده‌های مود نیز هست.
