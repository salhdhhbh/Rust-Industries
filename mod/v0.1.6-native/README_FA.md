# Rust Industries 0.1.6 — توسعهٔ صنعتی

این نسخه روی سورس Native نسخهٔ 0.1.5 توسعه داده شده است. نسخه‌های 0.1.3، 0.1.4 و 0.1.5 در شاخهٔ اصلی دست‌نخورده می‌مانند.

## ماشین‌های دارای مکانیک Native

| بلوک | مکانیک | ورودی / خروجی | زمان |
|---|---|---|---:|
| Crushing Wheel | خردکردن سنگ معدن آهن، مس و طلا به گرد فلز | سنگ معدن یا فلز ← ۲ گرد فلز | ۴۰ تیک |
| Millstone | آسیاب سنگ و استخوان | سنگ‌فرش ← شن؛ شن ← چخماق؛ استخوان ← ۳ پودر استخوان | ۶۰ تیک |
| Industrial Drill | استخراج مواد خام از سنگ معدن | سنگ معدن ← مادهٔ خام/کانی | ۸۰ تیک |
| Mechanical Press | تبدیل شمش به ورق | شمش فلزی ← ۲ ورق | ۶۰ تیک |
| Mechanical Mixer | ترکیب دو ورودی | گرد فلز یا الماس + آمیتیست ← Essence؛ سیم‌پیچ مس + ردستون ← برد مدار | ۸۰ تیک |
| Depot | ذخیره‌سازی | ۹ خانه | — |

ماشین‌های پردازشی نوار پیشرفت، وضعیت خروجی پر و فیلتر ورودی دارند. ورودی تا زمان وجود ظرفیت برای خروجی مصرف نمی‌شود.

## رفتار بلوک‌های کمکی

- Factory Chute و Factory Funnel از قالب رفتاری Hopper استفاده می‌کنند.
- Hand Crank از قالب Lever استفاده می‌کند و خروجی ردستون دارد.
- Basin از قالب Cauldron استفاده می‌کند.
- Mechanical Fan ضریب حرکت را ۱٫۲۰ برابر می‌کند.
- Shaft، Cogwheel، Gearbox، Motor و Water Wheel مدل/تکسچر اختصاصی دارند و در دستورهای ساخت صنعتی نقش قطعه دارند؛ شبکهٔ انتقال گشتاور بین آن‌ها هنوز پیاده‌سازی نشده است.
- چهار خانوادهٔ Crop هرکدام هشت مرحلهٔ رشد و تکسچر اختصاصی دارند.

## تکسچر و مدل

تکسچر اختصاصی برای تمام بلوک‌ها و آیتم‌های تعریف‌شده اضافه شده است. تکسچرهای بلوک/آیتم ۱۶×۱۶ هستند؛ مدل‌های ماشین‌ها هندسهٔ مخصوص دارند. ورق‌های آهن، مس، طلا و فولاد نیز اضافه شده‌اند.

## ساخت Native

پروژه برای Horizon Mod API 0.2 و Game 26.3 تنظیم شده است. آن را در Starling/Horizon وارد کن و Native Build همان Instance را اجرا کن.

اعتبارسنجی فایل‌های JSON، مدل‌ها، ارجاع تکسچرها و آرشیو انجام شده است. کامپایل Native و تست داخل بازی باید روی لانچر هدف انجام شود.
